# Phum Khnhom CMS-ready Website

This version is prepared for frequent posting.

## Important files
- `content/stories.json` = story database
- `.pages.yml` = Pages CMS setup
- `assets/uploads/` = uploaded images
- `app.js` = loads stories from JSON

## How to post
Use Pages CMS to add/edit Stories. It will save changes to GitHub, and Cloudflare Pages will redeploy automatically.

## Manual backup method
Edit `content/stories.json` in GitHub, then commit changes.
